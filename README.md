# Vibe Filter

**Turn any video into a hand-drawn cartoon, neon sketch, VHS tape, pixel-art game or oil painting, and give it a brand-new soundtrack that is composed from the video itself.**

Vibe Filter is a small app that runs on your own computer. You open it in your web browser, drop in a video, pick a look, and it renders a new copy of the clip. Nothing is uploaded to the internet: your videos stay on your machine.

It was built for the Mac, and it is free and open source (MIT license).

---

## What it does

### 1. Restyles the picture

Pick one of six looks:

| Style | What it looks like | Extra options |
| --- | --- | --- |
| **Classic** | Flat cel colors and an even ink line, like a 1950s cartoon short. | Color palettes: Original, Vintage Cartoon, Game Boy, Noir, Pop Art, Pastel, Sunset (turn on one or more, then *Combine* or *Mix* them). |
| **Fractal** | Fractal effects that grow from the edges in every frame, so they move with the video. | Tendrils, Fill, Echo, Glow (any mix). |
| **Neon Edges** | Glowing neon outlines over a darkened picture. | Color (Rainbow, Pink-Cyan, Single), glow strength, background brightness. |
| **VHS Retro** | Worn videotape: soft, warm, washed-out colors with a little color bleed. | Scanlines, Wobble, Grain (each can be turned off). |
| **Pixel Art** | Chunky square pixels in a limited set of colors. | Pixel size; Rich colors or a fixed Retro 16-color game palette. |
| **Oil Paint** | Flat patches of paint with visible brush strokes and thick-paint highlights. | Light, Medium or Strong. |

You can also choose the frame rate (8 to 24 frames per second; fewer frames gives a choppier, more hand-animated feel), the output width (640 px up to full size), and sliders for **Simplify**, **Outline** and **Color** (each style uses the sliders that make sense for it).

### 2. Writes a soundtrack for the clip (optional)

Choose a music style:

- **Ambient**
- **Lo-fi Chill**
- **Dreamy Arp**
- **Synthwave**

…or **Off** to keep the clip's original sound untouched.

The music is not picked from a library. Vibe Filter looks at the video (how bright it is, its colors, how saturated it is, and how much is moving) and uses that as the "seed" for a new piece of music. From that it chooses the key, the musical mode (from bright Lydian and Major through Dorian and Minor to dark Phrygian), the tempo and time signature, the chord progression, the melody, a counter-melody, the bass line and how busy everything is. The song follows a simple form with sections and a build to a high point.

**The same video and the same style always produce exactly the same song.** A different video gives you a different song.

Instruments come from a small set of real recorded samples (electric piano, muted guitar, finger bass, celesta, drums, and room reverbs) plus synthesizers built into the app. If the sample folder is missing, the app still works and synthesizes every part itself.

Music options:

- **Replace** or **Blend**: the music either replaces the clip's sound or plays underneath it.
- **Omit audio**: drop the original sound completely.
- **Ooh-aah** (off by default): adds a synthesized backing choir singing "ooh" and "aah".
- **Lyrics** (off by default): type or paste your own lyrics (one line of the song per line) and a built-in synthesized singing voice sings them to the melody. Words are turned into speech sounds using the CMU Pronouncing Dictionary. The voice is generated by the app from scratch (a classic "formant" speech synthesizer), not from recordings of a real singer.

### 3. Preview, then export

- **Preview** renders a short section (10 seconds by default; you pick the start point and length) so you can try settings quickly.
- **Export full clip** renders the whole video and saves it to **`Movies/Vibe Filter`** in your home folder. You can also download it from the page or click **Show in Finder**.
- A **Cancel** button stops a render that is in progress.

## What you need

- **A Mac.** (The "Choose…" file picker and "Show in Finder" use macOS features. The rest is plain Node.js and may work elsewhere, but the Mac is what it's made for.)
- **Node.js 18 or newer.** Get it from [nodejs.org](https://nodejs.org/) or with Homebrew: `brew install node`
- **ffmpeg** (does all the video work and reads the clip for the music). Install it with Homebrew: `brew install ffmpeg`. A recent version is recommended. Vibe Filter looks for it in `/opt/homebrew/bin`, `/usr/local/bin`, and then on your normal `PATH`.

There are **no other packages to install**: the app uses only what comes with Node.js, so there is no `npm install` step.

Don't have Homebrew? Install it from [brew.sh](https://brew.sh/).

## Install and run (Mac)

### Option A: double-click (easiest)

1. Click the green **Code** button on this page and choose **Download ZIP**, then unzip it. (Or use `git clone`, see Option B.)
2. Open the folder and double-click **`Start Vibe Filter.command`**.
   - The first time, macOS may say it can't be opened because it's from an unidentified developer. If so, **right-click** (or Control-click) the file, choose **Open**, then click **Open** again.
   - If it says you don't have permission, open Terminal in that folder and run `chmod +x "Start Vibe Filter.command"` once.
3. A Terminal window opens and your browser opens **http://127.0.0.1:4747**.
4. When you're done, close the Terminal window to stop Vibe Filter.

### Option B: from Terminal

```bash
git clone https://github.com/clawclawson-ctrl/vibe-filter.git
cd vibe-filter
npm start          # or: node server.js
```

Then open **http://127.0.0.1:4747** in your browser. Press `Ctrl+C` in Terminal to stop it.

### Settings (optional)

| Environment variable | What it does | Default |
| --- | --- | --- |
| `VIBE_FILTER_PORT` | Port the app listens on | `4747` |
| `VIBE_FILTER_ASSETS` | Use a different folder of instrument samples | the `assets/` folder in this project |

Example: `VIBE_FILTER_PORT=5000 npm start`

The app only listens on `127.0.0.1`, which means only your own computer can reach it.

## How to use it

1. **Load a video**: drag it onto the page, click **Choose…**, or paste its file path into the box.
2. **Pick a style** and adjust its options and the sliders.
3. **Pick a frame rate and width.** Smaller and slower renders faster.
4. **Music**: leave it **Off**, or pick Ambient, Lo-fi Chill, Dreamy Arp or Synthwave. Choose Replace or Blend, and optionally turn on Ooh-aah or Lyrics (click **Edit lyrics…** to type them).
5. Click **Preview** to try a short section. Move the *Preview start* slider or change the length to try a different part.
6. Happy with it? Click **Export full clip**. The finished video lands in `~/Movies/Vibe Filter`.

Tip: since the music comes from the picture, trimming or changing the clip changes the song. Try the same clip in different music styles: each style reads the video in its own way.

## Project structure

```
vibe-filter/
├── Start Vibe Filter.command   Double-click launcher for macOS
├── package.json                "npm start" runs server.js
├── server.js                   Local web server; builds the ffmpeg video filters and runs renders
├── music.js                    Reads the clip and synthesizes the soundtrack into a WAV file
├── genome.js                   Turns the video's measurements into a musical "genome": key, mode, tempo, meter, chords
├── arrange.js                  Song form, chord progression, melody motif, counter-line and walking bass
├── mixbus.js                   Mixing effects: EQ, chorus, stereo width, saturation, reverb sends
├── samples.js                  Loads the optional instrument samples from assets/
├── voice.js                    Synthesized singing voice for the Ooh-aah choir and Lyrics
├── public/                     The web page (index.html, app.js, style.css)
└── assets/                     Instrument samples, drum hits, room reverbs, pronouncing dictionary
    ├── ep/  mute/  bass/  celesta/  cym/   instrument notes (WAV)
    ├── drums/                               drum one-shots (WAV)
    ├── ir/                                  room reverb impulse responses (WAV)
    ├── cmudict/                             CMU Pronouncing Dictionary + its license
    └── LICENSES.md                          detailed source notes for every asset
```

Temporary files (uploads and previews) go in your system's temp folder under `vibe-filter/`, and are cleaned up the next time the app starts.
